# Быстрая установка

1. Распакуйте архив.
2. Скопируйте `custom_components/electrical_network` в `/config/custom_components/electrical_network`.
3. Перезапустите Home Assistant.
4. Добавьте интеграцию **Electrical Network Designer** в разделе **Настройки → Устройства и службы**.
5. Откройте новый пункт **Электросхема дома** в боковом меню.

После обновления файлов всегда выполняйте полный перезапуск Home Assistant и жёсткое обновление страницы браузера.
